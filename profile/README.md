# SPLectral

Components for SPLectral, the platform for seeing and working with running
systems in the browser. The components work in SPLectral's own abstract world
(hosts, nodes, resources named by URI, and their activity) and know nothing of
what runs underneath. The first system they show is a peer-to-peer swarm,
live, with scenarios recorded and replayed: views and scenarios, one a
repository.

SPLectral itself, its engine, is in
[pear-full-square](https://github.com/pear-full-square); the components are
put to use in the projects of **[HAICCing](https://github.com/haiccing)**:
start there.

Part of the engineering of [SPLectrum](https://splectrum.world).

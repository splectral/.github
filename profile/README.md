# SPLectral

Components for SPLectral, the browser platform for watching and acting on
P2P swarms: views and scenarios, one a repository. The platform is in
[pear-full-square](https://github.com/pear-full-square); the components run
in the projects of **[HAICCing](https://github.com/haiccing)**: start there.

Part of the [SPLectrum](https://splectrum.world) engineering infrastructure.
All components MIT licensed.
